# НИТЬ — сайт ателье

Демонстрационный адаптивный сайт мастерской пошива и ремонта одежды.

## Запуск
1. Клонируйте репозиторий или скачайте ZIP.
2. Откройте `index.html` в браузере.
3. Для разработки откройте папку в VS Code и запустите через Live Server.

## Структура
- `index.html` — разметка и контент
- `style.css` — адаптивные стили
- `script.js` — мобильное меню и демонстрационная обработка формы

## Возможности
- Адаптивная вёрстка для компьютеров и мобильных устройств
- Секции услуг, портфолио, о мастерской, прайс-лист и контакты
- Мобильное навигационное меню
- Демонстрационная форма заявки с проверкой полей

## Важно
Все данные мастерской, адрес, цены, телефон и отзывы вымышлены. Форма пока не отправляет заявки на сервер. Для реального сайта нужно подключить backend или сервис обработки форм, настроить согласие на обработку персональных данных и заменить контакты.

Фотографии загружаются с Unsplash, шрифты — с Google Fonts, поэтому для их отображения требуется интернет.
